---
title: Troubleshooting
---

Errors you may see while setting up or running Patrol, with the fix for each. Run `patrol doctor` first – it catches most environment problems. Then pick the category that matches your error:

- [General](/reference/troubleshooting/general) – version mismatches, the app not starting inside a test.
- [Android](/reference/troubleshooting/android) – `package_name`, JDK versions, builds that hang.
- [iOS](/reference/troubleshooting/ios) – `bundle_id`, simulators, Xcode build and deployment errors.

## Most common

- [Test runs but the app never starts](/reference/troubleshooting/general#faq-app-not-running-in-test)
- [Error inside `patrol_test/test_bundle.dart` (version mismatch)](/reference/troubleshooting/general#faq-test-bundle-error)
- [iOS: test stops on "Wait for … to idle"](/reference/troubleshooting/ios#faq-test-stops-wait-for-idle)

If you couldn't find an answer to your question/problem, feel free to ask on [Patrol Discord Server].
