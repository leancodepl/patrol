---
title: Commands and global flags
---

| Command | What it does |
| --- | --- |
| [`patrol develop`](/reference/cli/develop) | Develop tests with Hot Restart. |
| [`patrol test`](/reference/cli/test) | Build and run tests on a device. |
| [`patrol build`](/reference/cli/build) | Build the app with tests, without running them. |
| [`patrol test --test-without-building`](/reference/cli/test-without-building) | Run a previously built app. |
| [`patrol doctor`](/reference/cli/doctor) | Check that the environment is set up. |
| [`patrol update`](/reference/cli/update) | Update `patrol_cli`. |
| [`patrol devices`](/reference/cli/devices) | List connected devices. |

Global flags shared by every command will be documented here.
