---
title: Supported platforms
---

Patrol works on:

- Android 7.0 (API 24) and newer,
- iOS 13 and newer,
- macOS 10.15 and newer (alpha support),
- Linux desktop, for Dart-side (Flutter) interactions only: native actions throw `UnsupportedError`.
  See [Linux desktop](/cli-commands/test#linux-desktop).

Windows is not supported.

On mobile platforms it works on both physical and virtual devices.

If you want to check which native features are supported, see [feature parity].

[feature parity]: /documentation/native/feature-parity
